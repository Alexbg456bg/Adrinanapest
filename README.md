# Адрина ООД — уебсайт (ДДД услуги)

Нов сайт с React + Vite + Framer Motion за "Адрина ООД" — лицензирана ДДД фирма
в София (дезинсекция, дезинфекция, дератизация, дезакаризация). Замества стария
сайт на адрес adrinapest.com. Статичен, single-page каталожен сайт — контактната
форма изпраща имейл през малък PHP скрипт (без база данни), подходящо за
хостинг като SuperHosting.

## Стартиране на локална разработка

```bash
npm install
npm run dev
```

Сайтът тръгва на `http://localhost:5173`.

> Забележка: контактната форма праща заявка към `/contact.php`, което е PHP файл
> и няма да проработи през `npm run dev` (Vite не изпълнява PHP). Формата ще
> работи само след качване на хостинга — вижте раздела по-долу.

## Build за продукция

```bash
npm run build
```

Готовите файлове излизат в `dist/` — качват се директно в root папката на
хостинга (напр. `public_html/` в SuperHosting). Файлът `public/contact.php`
се копира автоматично в `dist/contact.php` при build.

## Структура

```
src/
  components/     — всяка секция на сайта е отделен компонент (Navbar, Hero, Services...)
  App.jsx         — подрежда секциите
  index.css       — дизайн токени (цветове, spacing) + глобални стилове
public/
  favicon.svg     — временна марка (щит + чек) — виж TODO по-долу
  contact.php     — обработва заявките от контактната форма (PHP mail())
```

## Съдържание — какво е реално и какво е временно

Реалното съдържание (услуги, лиценз, контакти, партньори) е взето от текущия
сайт adrinapest.com. Останалото, което трябва да се допълни/потвърди преди
пускане на живо:

- **Лого** — клиентът няма готово лого. Сегашният знак (`src/components/Logo.jsx`,
  `public/favicon.svg`) е временен (щит + чек в зелено), лесен за подмяна, щом
  има готово фирмено лого.
- **Работно време** (`src/components/Contact.jsx`, `CONTACT_INFO.hours`) —
  сложено е разумно по подразбиране (Пон–Съб 08:00–19:00), но трябва да се
  потвърди с клиента.
- **Точен адрес/офис** — в стария сайт е посочен само "гр. София", без улица.
  Ако има конкретен адрес на офиса, добавете го в `Contact.jsx`.
- **Снимки** — няма реални снимки на екипа/обектите. Вместо placeholder с
  пунктирана рамка, Hero и "Защо ние" ползват анимирани графични елементи
  (badge с "20+ години"), които изглеждат завършено и без снимки — но могат
  да се заменят с реални снимки на екипа по-късно за по-голяма автентичност.
- **Отзиви** (`src/components/Testimonials.jsx`) — примерни, анонимизирани
  ("Клиент — жилищен имот, София" и др.), ясно маркирани в кода с TODO.
  Заменете с реални отзиви на клиенти (с тяхно съгласие) преди пускане в
  реална експлоатация.
- **Партньори** (`src/components/Partners.jsx`) — реални, взети от стария
  сайт: ЙОД АД, Кинотеатър „Освобождение" София. Може да се разшири при
  наличие на още референции.

## Контактната форма (PHP, без база данни)

`public/contact.php`:

- Приема POST заявка с JSON тяло (`name`, `phone`, `email`, `service`, `message`).
- Изпраща имейл до `adrinapest@gmail.com` чрез вградената PHP `mail()` функция
  (SuperHosting поддържа `mail()` на споделен хостинг без допълнителна настройка).
- Има скрито honeypot поле (`company`) срещу спам ботове.
- Маха нови редове от входните полета, за да не позволи header injection.
- При въведен имейл от посетителя, слага `Reply-To`, за да можете директно да
  отговорите на запитването.

**След качване на хостинга:**

1. Качете съдържанието на `dist/` (вкл. `contact.php`) в `public_html/`.
2. Проверете, че PHP е активен за домейна (стандартно в SuperHosting е активен).
3. Тествайте формата на живия сайт — локално (`npm run dev`) няма да проработи.
4. Ако имейлите от `mail()` попадат в спам, обмислете смяна с SMTP през
   истинския пощенски акаунт на домейна (напр. PHPMailer + SMTP на SuperHosting)
   вместо вградения `mail()`.

## Хостинг

Клиентът вече има хостинг в **SuperHosting** — статичните файлове от `dist/`
плюс `contact.php` се качват директно там (FTP/файлов мениджър), няма нужда
от Node.js на самия хостинг — той е нужен само локално, за да се build-не сайтът.

## Технологии

- [Vite](https://vitejs.dev/) — build tool
- [React 18](https://react.dev/)
- [Framer Motion](https://www.framer.com/motion/) — анимации (scroll-reveal, hover, брояч на статистики, floating икони в Hero, анимиран progress ring)
- Плейн CSS с дизайн токени (без Tailwind/UI библиотека)
- PHP (само `contact.php`, за изпращане на имейл от контактната форма)

## Важна бележка

Проектът е разработен в среда без достъп до npm registry и без инсталиран
Node.js, затова **`npm install` и `npm run dev`/`build` не са тествани
оттук** — трябва да се изпълнят локално (на машина с Node.js), за да се
провери, че всичко работи и да се хване евентуална синтактична грешка.
